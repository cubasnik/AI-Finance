## Как создать Telegram-бота (шаги, которые мы прошли)

1. Открыть Telegram, найти **@BotFather**
2. Отправить `/newbot`
3. Указать отображаемое имя бота (например: `Мой Финансовый Бот`)
4. Указать username бота — обязательно оканчивается на `bot`
   (например: `myfinance_notify_bot`)
5. BotFather присылает **токен** вида:
   ```
   123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
6. Сохранить токен **только** в Apps Script (не в чат, не в текстовые заметки)

## Как получить Chat ID (шаги, которые мы прошли)

1. Написать боту любое сообщение в Telegram (например "привет") — просто
   найти бота по username и нажать **Start**
2. Открыть в браузере:
   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```
   (без угловых скобок, токен слитно после `bot`)
3. Если результат пустой (`"result": []`) — значит сообщение боту ещё не
   отправлено или Telegram не успел его зафиксировать; отправить сообщение
   ещё раз и обновить страницу
4. В ответе найти блок `"chat": { "id": ЧИСЛО, ... }` — это и есть Chat ID
5. У нас получилось: **597766797**

## Как создать Google-таблицу (шаги)

1. Открыть [sheets.google.com](https://sheets.google.com) → **Создать новую таблицу**
2. Назвать, например: `Финансы — Тест`
3. Заголовки первой строки (обязательно точное совпадение):
   ```
   Дата | Категория | Сумма | Описание | Статус | Ответственный
   ```
4. Для тестового наполнения: **Файл → Импорт → Загрузка** →
   выбрать `test_finance_template.csv` → **Заменить текущий лист**

### Категория — рекомендуемый выпадающий список

- Зарплата, Аренда, Налоги, Закупки, Софт, Маркетинг,

## Как интегрировать скрипт (шаги)

1. В открытой Google-таблице: **Расширения → Apps Script**
2. Удалить код по умолчанию, вставить содержимое `TelegramNotifier.gs` целиком
3. В начале файла заполнить:
   ```js
   const TELEGRAM_TOKEN = 'реальный_токен_от_BotFather';
   const CHAT_ID = '597766797';
   ```
4. Сохранить (Ctrl+S / Cmd+S)
5. В левом меню редактора нажать на функцию `testConnection` в выпадающем
   списке функций сверху → нажать ▶️ **Выполнить**
6. Google запросит разрешения — разрешить (это обращение к внешнему API
   Telegram, поэтому требуется подтверждение доступа)
7. Проверить Telegram — должно прийти: *"✅ Бот подключён успешно!..."*
8. Настроить триггер:
   - Значок часов (⏰) слева в редакторе → **Добавить триггер**
   - Функция для запуска: **`handleSheetEdit`** (НЕ `onEdit`!)
   - Источник события: **Из электронной таблицы**
   - Тип события источника: **При изменении**
   - Сохранить
9. Проверка: вписать новую строку в таблицу (Дата, Категория, Сумма
   обязательны) → должно прийти уведомление в Telegram

### ⚠️ Важно: почему функция называется `handleSheetEdit`, а не `onEdit`

Изначально функция называлась `onEdit`. Оказалось, что это зарезервированное
имя — Google Apps Script автоматически запускает **любую** функцию с таким
именем как "простой триггер", даже без создания триггера вручную. Когда
поверх этого создаётся ещё и установленный (installable) триггер с тем же
именем — получается двойное срабатывание и гонка состояний, из-за которой
случайным образом падает ошибка `Cannot read properties of undefined
(reading 'getSheet')`.

**Решение:** функция переименована в `handleSheetEdit`. Простой триггер
Google её не трогает (имя не совпадает с зарезервированным), срабатывает
только один установленный триггер — чисто и без конфликтов.

Если ты уже создавал триггер на `onEdit` раньше — **удали его** (значок
часов → корзина рядом со старым триггером) и создай новый на
`handleSheetEdit`, как описано в пункте 8 выше.

## Как это работает технически

- Скрипт следит за листом `Лист1` (переименовать константу `SHEET_NAME`,
  если лист называется иначе)
- Срабатывает при любом редактировании таблицы, но отправляет уведомление
  только если заполнены Категория и Сумма
- Защита от дублей: помечает отправленную строку в служебной скрытой
  колонке `_notified`
- Считает сумму трат за день и % использования месячного лимита по
  категории (лимиты — константа `BUDGET_LIMITS` в коде, можно менять)

## Известные ограничения на этом этапе

- Лимиты бюджета (`BUDGET_LIMITS`) заданы условно — нужно уточнить
  реальные цифры перед Фазой 2
- Скрипт привязан к одной таблице; при переходе на реальную (не тестовую)
  таблицу нужно повторно вставить скрипт и настроить триггер там
- `onEdit` триггер может не сработать при массовой вставке/импорте строк —
  для таких случаев потребуется отдельная функция (добавим при необходимости)
