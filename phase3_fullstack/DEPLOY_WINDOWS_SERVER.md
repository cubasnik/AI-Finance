# Развёртывание на Windows Server

## Что это даёт

- Собственная база данных на твоём сервере (SQLite, файл `finance.db`)
- Бухгалтер входит по логину/паролю и вносит данные через простую веб-форму
- Ты (владелец) видишь дашборд с полной аналитикой
- Telegram-уведомления теперь отправляет сам сервер (Google Sheets и
  Apps Script из Фазы 1 больше не нужны для этой части — они использовались
  только пока данные были в Google Sheets)
- **Google OAuth из Фазы 2 тоже больше не нужен** — вход через логин/пароль
  проще и находится полностью под твоим контролем

---

## Шаг 1 — Установить Node.js на сервере

1. Зайди на сервер (через RDP)
2. Скачай Node.js LTS: [nodejs.org](https://nodejs.org) → версия LTS → установщик для Windows
3. Запусти установщик, везде "Next", дождись завершения
4. Проверь в командной строке (`cmd`):
   ```
   node --version
   npm --version
   ```
   Обе команды должны показать номер версии

## Шаг 2 — Скопировать проект на сервер

1. Скопируй папку `phase3_fullstack` на сервер, например в:
   ```
   C:\AI_Finance\backend
   ```
2. Открой командную строку, перейди в эту папку:
   ```
   cd C:\AI_Finance\backend
   ```

## Шаг 3 — Настроить .env

1. Скопируй `.env.example` → переименуй копию в `.env`
2. Открой `.env` в блокноте, заполни:
   - `SESSION_SECRET` — любая длинная случайная строка (просто настучай на клавиатуре 40+ символов)
   - `OWNER_USERNAME` / `OWNER_PASSWORD` — твои логин/пароль
   - `ACCOUNTANT_USERNAME` / `ACCOUNTANT_PASSWORD` — логин/пароль для бухгалтера
   - `TELEGRAM_TOKEN` / `TELEGRAM_CHAT_ID` — те же, что использовались в Фазе 1
3. Сохрани файл

## Шаг 4 — Установить зависимости и инициализировать базу

В командной строке, находясь в папке проекта:
```
npm install
npm run init-db
```

Ты должен увидеть:
```
✓ Созданы лимиты бюджета по умолчанию
✓ Создан пользователь "alexey" (роль: owner)
✓ Создан пользователь "buhgalter" (роль: accountant)
База данных готова: finance.db
```

## Шаг 5 — Запустить сервер

```
npm start
```

Должно появиться:
```
✓ Финансовый сервер запущен: http://localhost:3000
```

Открой браузер на самом сервере: `http://localhost:3000` — должна открыться
страница входа.

## Шаг 6 — Доступ с других компьютеров (по IP)

По умолчанию сервер слушает все сетевые интерфейсы, так что с любого
компьютера в той же сети (или через интернет, если порт проброшен) можно
зайти по адресу:
```
http://IP_АДРЕС_СЕРВЕРА:3000
```

**Важно:** нужно разрешить порт 3000 в брандмауэре Windows:
1. Панель управления → Брандмауэр Windows → Дополнительные параметры
2. Правила для входящих подключений → Создать правило
3. Тип правила: **Порт** → Далее
4. TCP, конкретные порты: `3000` → Далее
5. Разрешить подключение → Далее → отметь все профили → Готово

## Шаг 7 — Чтобы сервер работал постоянно (не только пока открыта командная строка)

Проще всего — через **PM2** (менеджер процессов для Node.js):

```
npm install -g pm2
pm2 start server.js --name ai-finance
pm2 save
```

Чтобы PM2 сам запускался при перезагрузке Windows:
```
npm install -g pm2-windows-startup
pm2-startup install
```

Проверить, что сервер работает:
```
pm2 status
pm2 logs ai-finance
```

## Как пользоваться после установки

- **Бухгалтер** заходит на `http://IP_СЕРВЕРА:3000` → вводит свой логин/пароль
  → попадает сразу на форму внесения записи
- **Ты (владелец)** заходишь на тот же адрес → вводит свой логин/пароль →
  попадаешь на дашборд с полной аналитикой
- Каждая новая запись бухгалтера автоматически:
  1. Сохраняется в базе данных на сервере
  2. Отправляет уведомление в Telegram
  3. Сразу видна на твоём дашборде

## Резервное копирование

Вся база данных — это один файл `finance.db` в папке проекта. Достаточно
периодически копировать его в надёжное место (например, раз в день по
расписанию Windows — Планировщик заданий → копировать файл на сетевой диск
или в облако).

## Если нужен HTTPS и нормальный домен

Для полноценного продакшена (особенно если сервер будет доступен из
интернета, а не только по локальной сети) стоит:
1. Получить домен и направить его на IP сервера (A-запись)
2. Установить IIS или nginx как обратный прокси перед Node.js-сервером
3. Настроить бесплатный SSL-сертификат через Let's Encrypt (Certbot либо
   win-acme для Windows)

Это отдельная тема — дай знать, если сервер планируется открывать в
интернет, а не использовать только в локальной сети офиса, разберём отдельно.
