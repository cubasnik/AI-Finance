# Настройка приватного доступа через Google OAuth

Этот способ **не требует** публикации таблицы или открытия доступа по ссылке.
Дашборд получает данные напрямую от твоего Google-аккаунта, после того как
ты сам войдёшь в систему прямо в интерфейсе дашборда.

---

## Шаг 1 — Создать проект в Google Cloud

1. Открой [console.cloud.google.com](https://console.cloud.google.com)
2. Вверху слева — выбор проекта → **Новый проект**
3. Назови, например: `AI Finance Dashboard`
4. Нажми **Создать**, дождись создания, выбери этот проект

## Шаг 2 — Включить Google Sheets API

1. В левом меню: **API и сервисы → Библиотека**
2. Найди **Google Sheets API**
3. Нажми **Включить**

## Шаг 3 — Настроить экран согласия (OAuth consent screen)

1. **API и сервисы → Экран согласия OAuth**
2. Тип пользователей: **Внешний** → Создать
3. Заполни обязательные поля:
   - Название приложения: `AI Finance Dashboard`
   - Email для поддержки пользователей: твоя почта
   - Контактные данные разработчика: твоя почта
4. **Сохранить и продолжить**
5. На экране "Области действия" (Scopes) — нажми **Добавить область**,
   найди и выбери: `.../auth/spreadsheets.readonly` (только чтение таблиц)
6. **Сохранить и продолжить**
7. На экране "Тестовые пользователи" — нажми **Добавить пользователей**,
   впиши свой же Gmail-адрес (тот, под которым будешь входить)
8. Сохранить

> Приложение останется в статусе "Тестирование" — это нормально и не мешает
> тебе лично пользоваться дашбордом. Просто добавь себя в тестовые
> пользователи, как в пункте 7.

## Шаг 4 — Создать OAuth Client ID

1. **API и сервисы → Учётные данные**
2. **+ Создать учётные данные → Идентификатор клиента OAuth**
3. Тип приложения: **Веб-приложение**
4. Название: `AI Finance Dashboard Web`
5. **Авторизованные источники JavaScript** — добавь:
   ```
   http://localhost:8000
   ```
   (см. Шаг 5 — почему именно этот адрес)
6. **Создать**
7. Скопируй появившийся **Client ID** (вид: `123456-abc...apps.googleusercontent.com`)

## Шаг 5 — Запустить дашборд через локальный сервер

Google OAuth не разрешает работать напрямую с файлом (`file:///...`) —
нужен настоящий адрес вида `http://localhost`. Это делается одной командой.

**Если на компьютере установлен Python** (обычно да, даже на Windows):

1. Открой командную строку (Win+R → `cmd` → Enter)
2. Перейди в папку с дашбордом:
   ```
   cd C:\Users\Alexey\Desktop\min\AI_Finance\phase2_dashboard
   ```
3. Запусти:
   ```
   python -m http.server 8000
   ```
4. Открой в браузере:
   ```
   http://localhost:8000/dashboard.html
   ```
5. Не закрывай окно командной строки, пока пользуешься дашбордом —
   как только закроешь, локальный сервер остановится

## Шаг 6 — Подключить дашборд

1. В дашборде вставь свой **Client ID** (из Шага 4)
2. Вставь **ссылку на таблицу** (обычную, `.../edit?gid=0#gid=0` — подойдёт)
3. Проверь, что название листа указано верно (`Лист1`)
4. Нажми **🔐 Войти через Google**
5. Появится стандартное окно входа Google — выбери свой аккаунт,
   разреши доступ на чтение таблиц
6. Данные загрузятся автоматически

---

## Что это даёт с точки зрения конфиденциальности

- Таблица остаётся **полностью приватной** — доступ есть только у тебя лично
- Никто не может получить данные по ссылке — только через твой вход в Google
- Токен доступа хранится только в памяти браузера на время сессии,
  никуда не сохраняется и не передаётся третьим лицам

## Если что-то не работает

- **"Ошибка входа: redirect_uri_mismatch" или похожая** — проверь, что в
  Шаге 4 в "Авторизованные источники JavaScript" указан **точно** тот же
  адрес, с которого открыт дашборд (включая порт, например `:8000`)
- **"Access blocked: this app is not verified"** — нажми "Дополнительные
  настройки" → "Перейти на (название), небезопасно" — это нормально для
  твоего собственного приложения в тестовом режиме
- **Просто не открывается окно входа** — проверь, что скрипт
  `accounts.google.com/gsi/client` не заблокирован блокировщиком рекламы
